# ABC-XYZ анализ ассортимента на датасете Contoso_100k

## Обзор
Этот пет-проект — это полный цикл анализа ассортимента товаров с использованием ABC и XYZ методов на тестовом датасете Contoso_100k (около 200 000 записей о продажах). Проект включает расчёт категорий в PostgreSQL, импорт в Power BI, моделирование данных, визуализацию матриц, подсказок и детализации. 

Цель — показать, как глобальный анализ может отличаться от сегментированного (по месту продажи), и дать рекомендации по управлению запасами на основе категорий.

Проект разработан в диалоге с ИИ (Grok), где мы обсуждали логику, решали проблемы с данными, кодом и моделью. В итоге получился дашборд, который помогает выявить ценные товары, риски и оптимизировать ассортимент.

## 📊Основные шаги разработки

### 1. Подготовка расчётов в SQL

Начал с ABC-анализа по маржинальной прибыли за последние 2 года (данные с 2015 по апрель 2024, но взял последние 2 года, присутствующие в базе, для актуальности). ABC делит товары на A (80% прибыли), B (15%), C (5%).

После перешел к XYZ-анализу — по стабильности спроса (X — стабильный, Y — умеренные колебания, Z — высокая волатильность, ND — недостаточно данных).

- **ABC глобально:** Ранжирование по общей марже.
- **XYZ глобально:** По среднему и стандартному отклонению месячных продаж, порог ≥4 месяцев с продажами.
- **ABC с сегментом по месту продажи (countryname):** Локальный ABC внутри каждой страны и онлайн.
- **XYZ с сегментом по месту продажи (countryname):** Локальный XYZ внутри каждой страны и онлайн, порог ≥4 месяцев с продажами. Если в месте <4 месяцев с продажами — берём из расчет XYZ глобально.

### 2. Проблемы и решения в расчётах

- **Период анализа:** Данные старые (2015–2024), старые товары имели преимущество. Решение: взял последние 2 года для актуальности, отказался от нормализации на время жизни товара (чтобы не искажать).

- **Порог для XYZ:** Сначала 6 месяцев, но много товаров A выпадали из сегментированного расчет (88 товаров A попадали в расчете в категорию ND (нет данных)). Снизил до 4 месяцев в обоих расчетах — покрытие выросло, в ND осталось 12 товаров категории A в сегментированном расчете, но CV менее надёжный.

 **📈 Визуализация:**

![Порог для XYZ](/ABC%20-%20XYZ%20анализ%20SQL/Изображения/Установка%20порога.png)

- **Недостаток данных в сегменте:** В расчете для сегмента получалось мало месяцев с продажами по месту — XYZ не считался, надо было или еще меньше делать порог, что приводило анализ к фикции или резервный вариант на глобальный XYZ, что и было сделано.
Так же, из за этого, расчет делался не для конкретного магазина, а для страны и онлайн.

### 3. Импорт в Power BI и Модель Данных

**Модель:** Две таблицы фактов (глобальная и сегментированная), связь по productkey (двусторонняя для фильтрации продуктов) + 2 таблицы справочника для глобальной матрицы для решения проблемы описанной ниже.

### 4. Проблемы и решения в визуализации

- **Пустые ячейки вместо 0:** В глобальной матрице BLANK вместо 0. Решение: создал справочники категорий ABC/XYZ, связал с глобальной таблицей фактов — теперь 0 везде.

**📈 Визуализация:**

![Пустые ячейки вместо 0:](/ABC%20-%20XYZ%20анализ%20SQL/Изображения/Пустые%20ячейки%20вместо%200.png)

- **Цикл в модели:** Справочники + связь по productkey создавали цикл. Решение: односторонние связи, удаление лишних связей, USERELATIONSHIP в мерах для фильтрации продуктов. В итоге: глобальная матрица фильтрует сегментированную по продуктам без цикла.

- **Окраска ячеек:** Создана мера для окрашивания ячеек в матрице.

- **Детализация:** Создана таблица детализации, в которую попадаешь с главной матрицы. 
    - **Пример:** Выбрана ячейка CY на странице Анализ без сегмента. Попадаем на страничку детализации, оказывается что в сегментированном анализе, некоторые товары в категории BY.
    Важное замечание, в сегментированной матрице один и тот же товар может попасть в разную категорию, из за того, расчет ведется для каждого места продажи.

**📈 Визуализация:**

![Детализация:](/ABC%20-%20XYZ%20анализ%20SQL/Изображения/Страница%20детализации.png)

- **Подсказки:** Настроил страницу-подсказку с динамическим текстом (мера с рекомендациями по категориям ABC/XYZ).

- **Очистка фильтров:** Добавил кнопку через закладку.
